# TC-001 - Agregar un producto al carrito

## Información del caso de prueba

| Campo | Descripción |
|---|---|
| **ID** | TC-001 |
| **Título** | Agregar un producto al carrito |
| **Aplicación** | DemoBlaze |
| **Tipo de prueba** | Funcional |
| **Nivel de prueba** | Sistema |
| **Prioridad** | Alta |
| **Estado** | Pass |

## Objetivo

Verificar que un usuario pueda seleccionar un producto disponible en la página de DemoBlaze y agregarlo correctamente al carrito de compras.

## Precondiciones

- El sitio web de DemoBlaze debe estar disponible.
- El usuario debe encontrarse en la página principal.
- Deben existir productos disponibles en el catálogo.
- El navegador debe tener acceso a Internet.

## Datos de prueba

| Dato | Valor |
|---|---|
| Sitio | DemoBlaze |
| Categoría | Phones |
| Producto | Samsung galaxy s6 |

## Pasos de ejecución

| No. | Acción | Resultado esperado |
|---:|---|---|
| 1 | Ingresar a la página principal de DemoBlaze. | La página principal carga correctamente y muestra el catálogo de productos. |
| 2 | Seleccionar la categoría **Phones**. | Se muestran los productos pertenecientes a la categoría Phones. |
| 3 | Seleccionar el producto **Samsung galaxy s6**. | Se abre la página con el detalle del producto seleccionado. |
| 4 | Verificar la información del producto. | Se muestra el nombre, precio, descripción e imagen del producto. |
| 5 | Hacer clic en **Add to cart**. | DemoBlaze procesa la solicitud para agregar el producto al carrito. |
| 6 | Aceptar el mensaje de confirmación. | Se confirma que el producto fue agregado correctamente. |
| 7 | Hacer clic en **Cart**. | Se abre la página del carrito de compras. |
| 8 | Verificar el producto agregado. | El producto **Samsung galaxy s6** aparece dentro del carrito. |

## Resultado esperado

El producto **Samsung galaxy s6** debe agregarse correctamente al carrito de compras y debe aparecer en la lista de productos cuando el usuario ingrese a la sección **Cart**.

## Resultado obtenido

El producto seleccionado fue agregado correctamente al carrito y se mostró en la sección **Cart**.

## Estado de la prueba

**PASS - Prueba ejecutada correctamente.**

## Observaciones

La funcionalidad de agregar productos al carrito respondió de acuerdo con el comportamiento esperado. El producto seleccionado se mostró correctamente en el carrito después de realizar el proceso.
